Download Conduit

Conduit has a local macOS menu-bar preview now. The signed release artifact is still delayed, but the app wrapper can already supervise the control app, browser bridge, and clipboard daemon from a source checkout.

npm install
npm run build
npm run macos:package
open dist/macos/Conduit.dmg

The preview DMG contains Conduit.app, an Applications shortcut, and install notes. It is intentionally unsigned for now, so macOS may require right-click Open on first launch.

Do not enable embedded-block parsing for normal clipboard use. Compliance mode should remain exact-envelope-only unless you are deliberately testing an unsafe profile.

Current channel

Source checkout plus unsigned local DMG. The CLI, daemon, control app, browser bridge, and macOS menu-bar preview are available now.

Next channel

Signed and notarized macOS package with real release artifacts, hosted downloads, and production update metadata.

State directory

Runtime state lives in ~/.conduit, or CONDUIT_STATE_DIR for tests and isolated runs.

Conduit v0 is local-first and intentionally conservative by default.
