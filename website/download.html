Download Conduit

Conduit has a local macOS menu-bar preview now. The signed release artifact is still the next distribution gate, but the app wrapper can already supervise the control app and clipboard daemon from a source checkout.

npm install
npm run build
npm run macos:build
open dist/macos/Conduit.app
npm run conduit -- session create --label "Clipboard" --root "$PWD"
npm run conduit -- daemon start --interval-ms 1000
npm run app

Do not enable embedded-block parsing for normal clipboard use. Compliance mode should remain exact-envelope-only unless you are deliberately testing an unsafe profile.

Current channel

Source checkout. The CLI, daemon, local control app, and macOS menu-bar preview are available now.

Next channel

Signed and notarized macOS menu-bar package with real release artifacts and production update metadata.

State directory

Runtime state lives in ~/.conduit, or CONDUIT_STATE_DIR for tests and isolated runs.

Conduit v0 is local-first and intentionally conservative by default.
